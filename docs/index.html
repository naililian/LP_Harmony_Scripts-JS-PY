Get started

Each release contains only what is needed for that tool. The installer sets up the Harmony-side launcher; the compiled runtime and its dependencies remain separate from Harmony.

  1. Download the release for the tool you want to use.
  2. Close Toon Boom Harmony.
  3. Run the included installer.
  4. Open Harmony and find the tool in its toolbar or menu.
